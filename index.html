Implémentation technique :

  • Mon rôle : Exploitation de vulnérabilités web via une attaque XSS (Cross-Site Scripting) et exécution d'une attaque par force brute ciblée à l'aide de l'outil Hydra pour compromettre des identifiants.

Context: Academic project carried out in a group of 4 at Luminy. The objective was to design a corporate architecture (DMZ, internal network), audit its security, and actively exploit its vulnerabilities through custom attack scenarios.

Technical Implementation:

  • Implementation of an infrastructure with web servers (Apache), databases (MySQL) and directory (OpenLDAP).
  • Penetration testing: each group member developed and executed their own attack scenario.
  • My role: Exploitation of web vulnerabilities via an XSS (Cross-Site Scripting) attack and execution of a targeted brute-force attack using the Hydra tool to compromise credentials.
  • Defensive securing via intrusion detection with the Snort IDS and creation of NetFilter filtering rules.
>_ Trajectory & Evaluation

Skill Development: This project was a turning point in my approach to security. I learned to think like an attacker (Red Team) to structure defenses (Blue Team) much more effectively, moving from theory to real-world application.

Supervision DHCP Centralisée

Centralized DHCP Supervision

SAÉ Administration Réseaux & Systèmes Systems & Networks Admin Project

Contexte : Mise en place d'une architecture réseau multi-sites et développement d'un outil en Python pour la gestion centralisée des serveurs DHCP distants.

Implémentation technique :

  • Déploiement d'une architecture réseau virtualisée sous Debian 11 avec un serveur central faisant office de routeur NAT.
  • Configuration de VLANs (802.1Q) isolés et mise en place des services DHCP via dnsmasq.
  • Développement d'un outil CLI en Python exploitant la librairie Fabric pour l'administration distante via SSH (automatisation de l'attribution des adresses IP par adresse MAC).
  • Sécurisation des accès sans mot de passe via l'utilisation stricte de clés RSA, du fichier authorized_keys et configuration restreinte de sudo.
>_ Trajectoire & Évaluation

Montée en compétence : C'est la SAÉ qui m'a fait basculer dans l'automatisation d'infrastructure. Comprendre qu'une gestion de parc multi-sites ne peut plus se faire manuellement m'a poussé à gagner en rigueur algorithmique et à maîtriser des outils comme Fabric pour agir à grande échelle.

Context: Setup of a multi-site network architecture and development of a Python tool for centralized management of remote DHCP servers.

Technical Implementation:

  • Deployment of a virtualized network architecture on Debian 11 with a central server acting as a NAT router.
  • Configuration of isolated VLANs (802.1Q) and DHCP services via dnsmasq.
  • Development of a CLI tool in Python using the Fabric library for remote administration via SSH (automating IP address allocation by MAC address).
  • Securing passwordless access through strict use of RSA keys, the authorized_keys file, and restricted sudo configuration.
>_ Trajectory & Evaluation

Skill Development: This project shifted my focus towards infrastructure automation. Realizing that multi-site management cannot be done manually pushed me to improve my algorithmic rigor and master tools like Fabric to act at scale.

Debian 11 VLAN / NAT Python 3 Fabric (SSH) dnsmasq YAML
